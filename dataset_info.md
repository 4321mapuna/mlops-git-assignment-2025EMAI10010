# Dataset Information

## Palmer Penguins Dataset

The experiments in this project use the **Palmer Penguins dataset**, a commonly used dataset for classification and data-analysis exercises.

### Dataset Summary

* **Number of observations:** 344
* **Target variable:** Species
* **Number of species:** 3

### Species

* Adelie
* Chinstrap
* Gentoo

### Example Features

* Island
* Bill Length
* Bill Depth
* Flipper Length
* Body Mass
* Sex
* Year

### Prediction Task

The machine learning task is a **multiclass classification problem** where the objective is to predict the penguin species using the available physical and categorical features.

### Data Quality

Some observations contain missing values. Depending on the experiment configuration, preprocessing may include missing-value handling before model training.

### Dataset Reference

Palmer Penguins dataset originally collected and made available through the Palmer Station Long Term Ecological Research program.
